## Register

brand

## Users

Developers and technically-fluent operators who live in the browser and the
terminal: they automate web apps they're already logged into (Jira, Gmail,
Slack, Figma, Salesforce), run shell workflows, and coordinate parallel
agents. Secondary audience: Adobe-ecosystem practitioners migrating websites
to AEM Edge Delivery Services. They read man pages for fun and distrust
anything that smells like enterprise marketing.

## Product Purpose

SLICC is a browser-native AI agent: it runs entirely client-side, exposes a
UNIX-like shell in the browser, and uses your existing sessions — no server,
no API keys, nothing to approve. The site's job is to make a developer grin,
then install (npm / macOS app / Chrome extension) within one scroll.

## Brand Personality

Deadpan-playful engineer humor over precise technical claims — the ice-cream
backronym universe (Self-Licking Ice Cream Cone), strikethrough headline
gags, "Under the waffle hood.", a footer that is a live terminal session.
The redesign keeps every joke and sharpens the machine around it:
terminal-native, operationally transparent, data-led. The page should feel
like a beautifully engineered CLI that happens to be a website — precision-
tracked display type, stepped dark surfaces, accents deployed like syntax
highlighting. Confident, irreverent, never corporate.

## Anti-references

- Corporate SaaS gloss: gradient heroes, glassmorphism, stock photography,
  floating 3D blobs.
- Generic-2026-dark-SaaS silhouette (the "modernize" trap): centered hero +
  logo river + three-column features with icon chips — SLICC's spine is
  terminal chrome and color-blocked bands, not the template.
- Enterprise-vendor tone; anything that hides or dilutes the terminal.
- Softened palette: the accents are loud by identity — never pastel them.

## Design Principles

1. **The terminal is the brand.** Mono type, `$` prompts, traffic-light
   chrome and man-page structure are load-bearing; every section should
   survive the question "would this render in a terminal?"
2. **Color blocks do the work of imagery.** Full-bleed flat accent bands
   (green / crimson / orange) are the section-rhythm system; no gradients,
   no photos — the only large media are real product demo videos.
3. **Jokes are precise.** Every gag co-exists with an exact technical claim;
   humor never costs legibility (AA contrast everywhere, including the gags).
4. **Engineered rhythm.** One modular type scale (1.25), stepped dark
   surfaces instead of flat black, 64px section cadence — restraint between
   the loud bands is what makes them loud.
5. **96% of pages are man pages.** The template where the site actually
   lives gets the same design attention as the home page.
